# OpenPets Hoodie Cat artwork

Downloaded, existing artwork from OpenPets. No character artwork was drawn or generated for Family Guard.

Source: https://github.com/OpenPetsHQ/openpets
Pinned commit: `e36c98b1850af52e5246535b88e2e4de48e74f15`
Copyright (c) 2026 OpenPets. Licensed under MIT; the full notice is in LICENSE.txt and bundled with the app.

The three original WebP sprite atlases are used unchanged. Each cell is 192 x 208 pixels, in eight columns. The player uses the creator's published rows and frame counts for idle, right/left walking, waving, jumping, active gestures and thinking. Pajamas and Summer are alternate outfits of the same cat, not different animal species. Legacy cat/dog/bird choices migrate to the default outfit.

File URLs and SHA-256 hashes: source.json.
Animation definitions: apps/desktop/src/reaction-animation-mapping.ts at the same commit.
